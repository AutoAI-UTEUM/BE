# Definition of Done

| 항목 | 내용 |
| --- | --- |
| 상태 | 초안 |
| 마지막 갱신 | 2026-07-21 |

기능은 코드가 작성됐다는 이유만으로 완료되지 않습니다. 해당되는 항목을 모두 충족해야 합니다.

## 공통

- [ ] 연결된 요구사항 ID와 승인된 범위가 명확하다.
- [ ] 정상 흐름과 주요 예외 흐름이 동작한다.
- [ ] 관련 없는 변경이나 임시 디버그 코드가 없다.
- [ ] 비밀값·개인정보·정답 데이터가 로그/응답에 노출되지 않는다.
- [ ] 코드 리뷰와 필수 CI가 통과했다. (필수 CI의 구성은 기반 구축 Epic에서 확정하며, CI가 구축되기 전에는 테스트·빌드 수동 실행 결과를 PR에 기록하는 것으로 대체한다.)

## API

- [ ] 인증과 역할/소유권 검증이 있다.
- [ ] 요청 검증과 공통 오류 코드가 적용됐다.
- [ ] OpenAPI 예시와 실제 응답이 일치한다.
- [ ] `api-spec.md`, `screen-api-map.md`가 함께 갱신됐다.
- [ ] FE 분기에 필요한 안정된 오류 `code`가 [에러 코드](error-code.md)에 정의·반환된다(BE PR 시점 기준). 실제 FE 처리 확인은 기능 완료(Epic 연동 확인) 시점에 수행한다.

## 도메인/DB

- [ ] 핵심 비즈니스 규칙과 상태 전이가 Service 테스트로 검증됐다.
- [ ] DB 변경은 새 migration으로 재현된다.
- [ ] 필요한 제약조건과 최소 인덱스가 정의됐다.
- [ ] 기존 데이터 호환/백필/롤백 영향이 검토됐다.
- [ ] 정답/루브릭 등 비공개 데이터가 DTO에서 분리됐다.

## AI 연동

- [ ] Spring-FastAPI request/response 스키마 버전이 합의됐다.
- [ ] timeout, 오류, 잘못된 JSON, 알 수 없는 액션을 안전하게 처리한다.
- [ ] 중복 턴/재전송이 중복 메시지나 채점을 만들지 않는다.
- [ ] 실제 Grok 없이 CI에서 계약을 검증할 수 있다.
- [ ] AI 결과 반영 전에 상태 전이와 불변식을 검증한다.

## 테스트

- [ ] 핵심 Service 단위 테스트가 있다.
- [ ] Controller 계약/인증 테스트가 있다.
- [ ] 필요한 Repository/통합 테스트가 있다.
- [ ] 버그 수정은 재현 테스트가 먼저 또는 함께 추가됐다.
- [ ] 테스트 실행 방법과 결과가 PR에 기록됐다.

## 운영

- [ ] 환경 변수/설정 변경이 문서화됐다.
- [ ] 로그에서 요청을 추적할 수 있고 민감정보는 마스킹된다.
- [ ] health/readiness와 배포 smoke test 영향이 확인됐다. (smoke test 구성 항목은 배포 Epic에서 확정하며, 구축 전에는 해당 없음으로 표기한다.)
- [ ] 장애 시 rollback 또는 안전한 비활성화 방법이 있다.

## 문서 전용 변경

- [ ] 링크가 유효하다.
- [ ] 확정/초안/TBD가 구분되어 있다.
- [ ] 기존 기준과 충돌하면 우선순위와 결정 이유가 기록되어 있다.
- [ ] 구현되지 않은 내용을 구현 완료처럼 표현하지 않는다.
