# [Epic] 인증·사용자 기능 구축

## 목적

사용자가 회원가입·로그인 후 JWT로 자신의 정보와 보호된 EduPilot 기능에 접근할 수 있게 한다.

## 범위

- `LEARNER | INSTRUCTOR` 역할 선택 회원가입, 로그인, 내 정보 조회
- 비밀번호 해시와 JWT 발급·검증
- 인증 실패·권한 실패 공통 응답
- FE 인증 화면과 인증 상태 연동

## 제외

- OAuth·소셜 로그인
- 비밀번호 찾기·이메일 인증
- 상세 관리자 기능
- 강사 전용 기능·차등 권한(#102)

## 하위 작업

- [ ] JWT access/refresh 정책 확정
- [ ] Auth/User 외부 API 계약 승인
- [ ] Spring Security·User 저장·인증 API 구현
- [ ] FE 회원가입·로그인·인증 상태 연동
- [ ] 인증 정상·실패·위조·만료 통합 검증

## 완료 조건

- [ ] 회원가입·로그인·내 정보 흐름이 동작한다.
- [ ] 비밀번호 원문과 토큰·비밀값이 저장소 또는 로그에 노출되지 않는다.
- [ ] 누락·만료·위조 토큰이 합의된 오류로 거부된다.
- [ ] Swagger, 오류 코드, FE 호출이 실제 구현과 일치한다.
- [ ] 핵심 인증·인가 테스트가 통과한다.
