# [Epic] PDF 학습 자료 처리 구축

## 목적

인증된 사용자가 PDF를 업로드·조회하고, 세션과 AI 기능이 사용할 페이지 수와 페이지별 문맥을 안정적으로 제공받게 한다.

## 범위

- PDF 업로드·목록·상세 조회
- 원본 저장, 형식·크기 검증, 처리 상태 관리
- 페이지 수와 페이지별 텍스트 문맥 생성
- FE 업로드·조회·처리 상태 표시

## 제외

- PDF 편집
- 고도화 OCR
- 공개 파일 공유와 Course 계층

## 하위 작업

- [ ] 파일 저장소·텍스트 추출 책임·업로드 제한 확정
- [ ] Material API와 처리 상태 계약 승인
- [ ] 자료·페이지 schema, 업로드·조회·추출 구현
- [ ] FE 업로드·목록·상세·상태 UI 연동
- [ ] READY/FAILED·비인가 접근 통합 검증

## 완료 조건

- [ ] 유효한 PDF가 저장되고 페이지 문맥이 생성된다.
- [ ] 처리 중·완료·실패 상태를 조회할 수 있다.
- [ ] 손상·제한 초과 파일과 타인 자료 접근이 거부된다.
- [ ] FE가 업로드부터 처리 결과까지 표시한다.
- [ ] 업로드·조회·실패 흐름 테스트가 통과한다.
