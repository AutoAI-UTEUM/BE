# [Epic] 학습 세션·페이지 상태 관리

## 목적

PDF 학습 세션을 생성하고 현재 페이지·메시지·진행 상태를 복원하며, PDF 뷰어와 서버 상태를 일관되게 동기화한다.

## 범위

- 세션 생성·조회·완료와 메시지 복원
- 페이지 이동과 StateReducer 처리
- 소유권·활성 상태·페이지 범위 검증
- FE 세션 진입·재진입·PDF 뷰어 동기화

## 제외

- AI 설명·QA·퀴즈 생성
- 세션 공유와 공동 학습

## 하위 작업

- [ ] 세션·페이지 상태 모델과 API 계약 승인
- [ ] 세션·메시지 schema 및 세션 API 구현
- [ ] LLM 없는 페이지 이동 StateReducer 구현
- [ ] FE 세션 복원·PDF 페이지 동기화
- [ ] 생성→이동→새로고침→완료·충돌 흐름 검증

## 완료 조건

- [ ] READY 자료로 세션을 만들고 재진입할 수 있다.
- [ ] 현재 페이지와 메시지가 서버 기준으로 복원된다.
- [ ] 페이지 이동은 LLM 호출 없이 처리된다.
- [ ] 타인·완료 세션과 범위 밖 페이지 변경이 거부된다.
- [ ] FE 뷰어와 서버의 현재 페이지가 일치한다.
