# [Epic] AI 학습 턴: 페이지 설명·질의응답·스트리밍

## 목적

사용자가 현재 PDF 페이지 설명을 받고 같은 문맥에서 질문을 이어갈 수 있게 하며, 응답을 실시간으로 점진 표시한다.

## 범위

- Spring 턴 API와 FastAPI Orchestrator/Policy/Dispatcher 계약
- 현재 페이지 중심 ExplainerAgent 설명
- 새 질문·후속 질문을 구분하는 QaAgent·QaThread
- AI 결과·상태 패치 검증과 메시지 저장
- FE 설명·질문 UI와 Markdown 표시
- SSE 기반 응답 스트리밍·취소·재연결

## 제외

- 퀴즈 생성·채점
- 오개념 교정
- 장기 메모리 승격
- 내부 사고과정 원문 노출

## 하위 작업

- [ ] 학습 턴 외부/내부 API와 UI action 계약 승인
- [ ] Spring AI client·소유권 검증·결과 저장 구현
- [ ] FastAPI 설명·QA 오케스트레이션과 에이전트 구현
- [ ] FE 설명 선택·질문·후속 질문 흐름 연동
- [ ] 정상·timeout·잘못된 JSON·중복 요청 통합 검증
- [ ] 스트리밍 프로토콜과 UX 구현

## 완료 조건

- [ ] 현재 페이지 설명과 근거 기반 QA가 동작한다.
- [ ] 새 질문과 후속 질문의 문맥이 올바르게 분리·연결된다.
- [ ] Spring이 AI 결과와 허용된 상태 변경만 저장한다.
- [ ] 설명·QA 응답이 점진적으로 표시되고 완료 후 최종 메시지가 한 번만 저장된다.
- [ ] 연결 종료·취소·재연결이 세션 상태와 메시지를 손상시키지 않는다.
- [ ] 근거 부족·timeout·스키마 오류가 합의된 방식으로 처리된다.
- [ ] 실제 Gemini 없이 계약 테스트가 통과한다.
