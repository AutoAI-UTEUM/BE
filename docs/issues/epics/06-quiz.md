# [Epic] 퀴즈 생성·제출·채점

## 목적

학습 범위에서 네 가지 유형의 퀴즈를 생성하고, 답안을 안전하게 제출·채점하여 일관된 결과를 저장한다.

## 범위

- MCQ·OX·SHORT·ESSAY 퀴즈 생성
- 문제·정답·루브릭의 공개/비공개 DTO 분리
- 답안 제출과 재제출·중복 요청 정책
- MCQ/OX Spring 채점
- SHORT/ESSAY GraderAgent 채점과 Spring 검증
- FE 퀴즈 선택·풀이·결과 화면

## 제외

- 저득점 진단·오개념 교정
- 장기 학습자 메모리

## 하위 작업

- [ ] 퀴즈·제출·채점 API와 재제출·통과 정책 승인
- [ ] QuizAgent와 생성 결과 검증·저장 구현
- [ ] 제출 상태·MCQ/OX 결정론적 채점 구현
- [ ] SHORT/ESSAY AI 채점과 점수 범위 검증 구현
- [ ] FE 퀴즈 풀이·제출·결과 연동
- [ ] 정답 비노출·중복 제출·채점 실패 통합 검증

## 완료 조건

- [ ] 네 유형 퀴즈가 지정 학습 범위를 근거로 생성된다.
- [ ] 제출 전 정답·루브릭이 사용자 응답에 노출되지 않는다.
- [ ] 유형별 책임에 따라 채점되고 결과가 한 번만 저장된다.
- [ ] 타인 퀴즈·잘못된 상태·점수 범위 오류가 거부된다.
- [ ] 생성부터 결과 표시까지 통합 테스트가 통과한다.
