# [Epic] 평가·진단·오개념 교정·학습자 메모리

## 목적

채점 결과를 다음 학습 행동에 활용하고, 저득점 시 진단 질문과 짧은 교정을 제공하며 반복 근거가 있는 패턴만 개인화 메모리로 승격한다.

## 범위

- QuizAssessment 생성과 최근 평가 기록
- 저득점 QuizDiagnosis와 진단 답변 대기 상태
- MisconceptionRepair와 교정 후 QA 연결
- 진단·교정 근거 저장
- 반복 근거 기반 LearnerMemory 후보·승격·digest와 에이전트 개인화 반영

## 제외

- 단일 결과만으로 장기 메모리 확정
- 자동 임상·심리 진단
- 전체 페이지를 반복 설명하는 교정

## 하위 작업

- [ ] 통과 기준·평가 보관·메모리 승격 정책 승인
- [ ] Assessment·Diagnosis·Repair 내부 계약 구현
- [ ] Spring 진단 대기 상태·근거 기록·소유권 검증 구현
- [ ] FE 진단 질문·답변·교정 후 QA 흐름 연동
- [ ] 저득점→진단→교정 전체 흐름 검증
- [ ] 임시 후보와 장기 메모리 승격·digest 반영 구현

## 완료 조건

- [ ] 채점 후 근거가 있는 평가가 저장된다.
- [ ] 저득점 시 정답을 바로 주지 않고 진단 질문을 거친다.
- [ ] 교정은 확인된 헷갈린 개념에 집중하고 후속 QA로 연결된다.
- [ ] 단일 퀴즈·질문만으로 장기 메모리가 확정되지 않는다.
- [ ] 반복 근거가 있는 후보는 장기 메모리로 승격되고 이후 설명·QA·퀴즈·교정에 반영된다.
- [ ] 승격 근거와 변경 이력을 추적할 수 있다.
- [ ] 정상·중복·잘못된 진단 상태 테스트가 통과한다.
