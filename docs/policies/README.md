# 정책 문서 1.0 게시 체크리스트

`terms-1.0-draft.md`와 `privacy-1.0-draft.md`는 현재 서비스 구조를 반영한 실무 초안입니다. 법률 자문을 대신하지 않으며, 아래 확인이 끝나기 전에는 관리자 API로 게시하지 않습니다.

## 게시 전 필수 확인

- 모든 `[[...]]` 치환 항목을 실제 운영 정보로 교체한다.
- 운영 주체의 법적 명칭, 대표자, 주소, 사업자 정보와 고객 문의 채널을 확인한다.
- 개인정보 보호 책임자 또는 담당 부서와 정보주체 권리 행사 채널을 확정한다.
- AWS 리전, 로그·백업·탈퇴 데이터 보존 기간을 실제 운영 설정과 대조한다.
- Google, AWS, SpaceXAI LLC 등 처리위탁·국외 이전 현황과 계약 당사자를 확인한다.
- xAI 팀의 ZDR 사용 여부와 API·Files 보관 설정을 실제 콘솔 및 계약서에서 확인한다. 개인 정보가 포함될 수 있다면 xAI DPA와 ZDR 적용 요건을 별도로 검토한다.
- 만 14세 미만 가입을 차단하고, 별도 법정대리인 동의 절차를 구현하기 전에는 허용하지 않는다.
- 학교·기관이 학생 정보를 대신 제공하는 운영 방식이 있다면 별도 계약과 개인정보 처리 역할을 검토한다.
- 최종 문구를 개인정보 보호 담당자 또는 법률 전문가가 검토한다.

## 게시 원칙

- 이용약관은 `requiresConsent: true`로 게시한다.
- 개인정보 처리방침은 공개 고지 문서이므로 `requiresConsent: false`로 게시한다.
- 두 문서는 같은 시행일을 사용할 필요가 없으며, 변경 시 새 버전으로 게시한다. 기존 버전은 수정하지 않는다.
- `0.9`는 법무 검토 전 placeholder이므로 동의를 요구하지 않는다.

## 검토 기준

- 개인정보 보호법 제30조의 처리방침 필수 기재사항
- 개인정보보호위원회 개인정보 처리방침 작성지침과 AI·에듀테크 분야 평가 기준
- 약관의 규제에 관한 법률 제3조의 명시·설명의무
- SpaceXAI Enterprise Terms, DPA 및 API Security 문서의 보관·ZDR 조건

초안은 위 기준을 반영했지만 실제 처리 현황과 계약 내용을 대신 확인하지 않습니다. 운영 정보와 수탁 계약을 대조한 뒤 개인정보 보호 담당자 또는 법률 전문가의 최종 검토를 받습니다.

예시 요청:

```json
{
  "type": "TERMS",
  "version": "1.0",
  "title": "으뜸 이용약관",
  "content": "확정된 Markdown 본문",
  "summary": "최초 정식 약관",
  "requiresConsent": true,
  "effectiveAt": "[[UTC ISO 8601 시행 시각]]"
}
```
