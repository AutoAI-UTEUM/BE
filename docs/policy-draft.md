# 이용약관·개인정보처리방침 검토용 골격 (#415)

> **실제 서비스 약관이 아닙니다.** 아래 각 절은 학교·개인정보 보호 담당자·법무 검토를 위한 초안입니다. V48의 `0.9` 문서는 이 문서로 안내하는 placeholder만 담고 있으므로, 검토된 문구 `1.0` 등록 및 FE 공개 일정 확정 전에는 운영 약관으로 취급하면 안 됩니다. 수집·위탁·국외 이전의 법적 근거와 보존 기간은 아래 표만으로 확정되지 않습니다.

**2026-10-08 검토 기준:** 첫 출시는 만14세미만을 포함하고 업체 없는 TEAM_REVIEW를 사용한다는 기존 결정을 반영한 [약관1.0 초안](policies/terms-1.0-draft.md), [처리방침1.0 초안](policies/privacy-1.0-draft.md), [공식 출처·게시 전 검토표](policies/launch-review-20261008.md)를 함께 사용합니다. `1.0`은 후보이며 최종 문구·시행일·필수 여부·관계증빙·미정 보유/탈퇴 예외는 아직 승인되지 않았습니다. 아래 source 설명은 PR541 `58df7c95f11fa10c3b70a97e4a6fa9ecd152ed2e` 기준이며 실제 DEV 배포 완료를 뜻하지 않습니다. 준비 오류503은 정책 문구 승인이나 동의 전 아동 정보 수집의 적법성 신호가 아닙니다.

## 이용약관 초안

### 1. 서비스 정의 [법무 검토]

EduPilot은 강의 PDF 기반 설명·질의응답·퀴즈·채점·교정 및 학습 활동 관리 기능을 제공하는 교육 보조 서비스입니다. 제공 주체, 연락처, 적용 대상과 시행일은 운영 주체가 확정해야 합니다.

### 2. 계정과 이용자의 책임 [법무 검토]

이용자는 본인 명의의 이메일 또는 Google 계정으로 가입하고, 로그인 수단을 타인과 공유하지 않으며, 업로드 자료와 답안에 대한 적법한 이용 권한을 확보해야 합니다. 강의자·학습자·관리자 권한 범위, 계정 정지·탈퇴 절차와 이의 제기 경로를 확정해야 합니다.

### 3. 금지 행위 [법무 검토]

타인의 계정·자료 무단 접근, 권리 침해 자료 업로드, 서비스 방해, AI 출력을 이용한 부정행위 등 금지 범위와 조치 절차를 운영 정책에 맞춰 확정해야 합니다.

### 4. AI 생성물의 성격과 책임 [법무 검토]

AI의 설명·답변·퀴즈·채점·교정은 교육 보조이며 오류나 누락이 있을 수 있습니다. 학습·평가·교육상 최종 판단 주체, 이의 제기 및 정정 절차, 서비스 중단·장애의 책임 범위는 별도로 확정해야 합니다.

### 5. 변경과 고지 [법무 검토]

정책 버전, 시행일, 변경 요약을 게시하고 필요한 경우 새 버전 동의를 받습니다. 사전 통지 기한과 고지 채널은 법무 검토 후 확정합니다. 일반 정책 재동의 안내와 신규 가입 검증은 구분합니다. PR541은 필수가입동의 설정ON/유효 필수 문서0개이면 SIGNUP_POLICY_NOT_READY503, 준비 후 동의 누락·중복·버전 불일치이면 POLICY_CONSENT_REQUIRED400을 반환합니다. 문서별 requiresConsent 계약과 기존 계정 예외를 유지하며, 두 문서 모두의 존재/필수 선택을 강제하는 별도 정책은 이번 초안에서 결정하지 않습니다.

## 개인정보처리방침 초안

### 2. 외부 AI 처리·국외 전달 [법무 검토]

설명·질의응답·퀴즈·채점·오개념 교정 및 노트 생성 등을 위해 학습 대화·질문·답안·노트 생성 요청과 업로드 자료의 PDF 텍스트·이미지 또는 원본 파일이 **xAI(Grok)** 측으로 전송될 수 있습니다. 업로드 파일은 xAI Files에 저장되어 서버의 `xaiFileId`로 연계되며, 서비스의 자료 삭제·회원 탈퇴 시 [삭제 원장](deletion-journal.md)에 의도를 기록하고 정책·활성화 조건을 만족한 정리 경로가 파일 삭제를 시도합니다. 원장 기록은 실제 외부 파일 파기 완료가 아니며, 실패 재시도·미완료 추적과 xAI 자체 보존기간은 실제 운영 증거가 필요합니다.

수신국·법인은 이 초안에서 확정하지 않습니다. 과거 미국 리전 가정은 실제 계약·계정 설정의 증거가 아닙니다. 실제 국가·리전·하위 처리자·국외 이전 근거·거부 방법을 운영 주체와 xAI 계약 자료로 확인해야 합니다. 공개 문구에는 수신자, 국가, 이전 항목·시점·방법, 목적, 보유기간 및 이용자 권리를 확정해 넣어야 합니다. xAI의 최신 보존·삭제 정책 링크: **[운영 계약에 맞는 공식 URL 입력 필요]**. 단순 웹 공개 문서와 계약 조건이 다를 수 있습니다.

### 3. 저장 위치·백업·로그 [법무 검토]

주 데이터베이스·파일 저장 인프라의 실제 계약·리전과 DB/S3 백업 기간은 운영 근거가 필요합니다. #408 런북의30일을 모든 백업에 적용된 사실로 보지 않습니다. DEV main/ai CloudWatch 로그 각14일은 2026-10-06 사용자 완료 보고로 [운영 인수 기록](qa/operations-acceptance-20261007.md)에 보존돼 있으며 재조회·설정 변경을 요구하지 않습니다. PROD·다른 종류의 로그 기간은 별도 미확인입니다. `email_deliveries` 발송 이력과 [만료형 암호화 outbox 본문](mail-outbox.md)을 구분하고, logging provider의 본문/토큰 비로그와 모든 메일 본문 비저장을 혼동하지 않습니다. 메일·동의·감사·외부 사본의 최종 보유기간은 미정입니다.

### 4. 보관·파기 현황 [법무 검토: 실제 코드와 일치 여부 재확인 필수]

| 데이터 | 현재 탈퇴 구현에서 확인한 동작 | 아직 확정할 사항 |
| --- | --- | --- |
| 사용자 계정 | `users` 행을 삭제하지 않고 `DELETED` 상태로 변경. 이메일은 `deleted_{id}`, 이름은 고정 문구로 치환하고 소속·아바타 키·Google 식별자·기존 동의 메타를 비움. 비밀번호 해시를 로그인 불가 값으로 교체 | 잔존 user ID와 재식별 가능성 검토 |
| 인증 수단·아바타 | refresh 토큰·인증 세션 폐기, 아바타 삭제 의도 원장 기록 | 실제 파일·외부 캐시·백업 정리와 반영 시점 별도 확인 |
| 개인 학습 세션·소유 자료 | 세션·소유 자료 소프트 삭제와 삭제 의도 원장 기록. 외부AI/PDF/렌더 정리는 정책과 worker 활성화 조건을 따름 | 일반 소유자 요청 PDF/렌더30일은 승인된 별도 목적. 탈퇴 원본·연결 데이터·외부 사본의 미정 보존과 실제 파기 범위 확인 |
| 대화·퀴즈·시험·노트 등 연결 데이터 | 회원 탈퇴 API에서 일괄 물리 삭제하지 않음 | 목적별 보존기간·삭제 요청 처리 방식 설계 필요 |
| 정책 동의 이력 | `policy_consents`는 수정·삭제하지 않으며 탈퇴 후에도 잔존 `users.id`를 참조; 익명화 여부 미판정 | 법적 증적 보존기간·익명화 및 재식별 가능성 검토 |
| AI 사용량·감사/접속 로그·집계 | 일부는 별도 저장되거나 로그 플랫폼에 남음. `ai_usage_log`는 사용자 FK 없음 | 원문/식별자 보존 및 파기 주기 결정 |

이 표는 **현재 구현의 사실 확인표**이지 “탈퇴 즉시 모든 개인정보 완전 삭제”를 약속하는 문구가 아닙니다. 요구되는 파기 범위와 실제 코드가 다르면 정책 공개 전에 별도 구현 이슈로 정합화해야 합니다.

### 5. 이용자 권리 및 연락처 [법무 검토]

이용자의 열람·정정·삭제·처리정지·국외 이전 관련 요청을 받을 관리자 문의 경로, 처리 기한 및 불복 절차를 운영 주체가 확정해야 합니다. 현재 서비스에는 모든 자료를 자동 다운로드·일괄 파기하는 API가 없으므로 없는 기능을 보장하지 않습니다.

### 6. 안전성 확보 조치 [법무 검토]

비밀번호 해시, JWT·역할·리소스 소유권 검증, 관리자 API의 DB 역할 재검증과 구조화 감사 로그, 인프라 접근통제 및 저장·전송 암호화를 실제 배포 설정과 대조해야 합니다. 구체적인 암호화 알고리즘·키 관리·위탁 운영 내용을 확인 후 게시 문구로 확정합니다.

### 7. 적용 대상 [법무 검토]

첫 출시는 만14세미만을 포함하고 업체 없는 TEAM_REVIEW를 사용합니다. KST 연도 차이≤14는 보수적인 보호자 절차 제품 조건이며 법정 만 나이 또는 모든 미성년 이용계약 동의 판단을 대체하지 않습니다. 이메일/보호자 확인 전 해당 이용·외부 AI 제한을 유지합니다. 관계 확인·동의 전 계정 항목·미성년 이용계약·최종 고지·승인/증거 기간은 검토가 필요하며, 학교/기관별 데이터 처리 책임도 실제 이용 형태에 따라 별도로 확인합니다. 미구현 확인이나 미정 정책을 성공으로 간주하지 않습니다.
