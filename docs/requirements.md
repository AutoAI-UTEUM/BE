# 요구사항 명세서

| 항목 | 내용 |
| --- | --- |
| 상태 | 초안 |
| 마지막 갱신 | 2026-07-21 |
| 우선순위 | Must / Should / Could |

## 1. 권한

| 주체 | 가능한 행동 |
| --- | --- |
| 비회원 | 회원가입, 로그인 |
| USER | 본인 정보 조회, **본인이 업로드한 자료** 조회/업로드, 본인 세션과 퀴즈·메모리 사용 |
| ADMIN | 사용자와 자료 관리 기능(상세 범위 TBD) |
| Spring | 상태/데이터 저장, 권한 검증, 결정적 채점, FastAPI 호출 |
| FastAPI | 전달받은 문맥 안에서 AI 계획과 생성 수행 |

모든 리소스 접근은 역할뿐 아니라 소유권을 검증합니다. `TEACHER`는 현재 요구사항에 포함하지 않습니다.

## 2. 기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| AUTH-001 | 사용자는 이메일, 비밀번호, 이름으로 가입할 수 있다. | Must |
| AUTH-002 | 사용자는 로그인 후 JWT access token을 발급받을 수 있다. | Must |
| AUTH-003 | 인증된 사용자는 자신의 정보를 조회할 수 있다. | Must |

| AUTH-005 | refresh token 발급·회전·폐기를 제공한다(HttpOnly 쿠키, 회전·재사용 감지 — DEC-004). | Must |

## 3. 공통 예외 상황

- 인증 토큰 누락/만료/위조
- 다른 사용자의 자료, 세션, 퀴즈, 메모리 접근
- 존재하지 않거나 처리 중/삭제된 PDF
- 페이지 범위 초과
- 완료된 세션에 턴 또는 페이지 이동 요청
- 지원하지 않는 이벤트/퀴즈 타입
- 이미 제출된 퀴즈 재제출
- AI 응답 시간 초과, 스키마 오류, 정책 검증 실패
- 스트리밍 중 연결 종료
- 같은 이벤트의 중복 전송
- DB 저장은 실패했지만 AI 호출은 성공한 부분 실패

오류 응답 계약은 [에러 코드](error-code.md)를 따릅니다.

## 4. 비기능 요구사항 초안

- 모든 시간은 서버 저장 시 UTC를 사용하고 API는 ISO-8601로 표현합니다.
- 식별자는 BIGINT AUTO_INCREMENT를 내부·외부 겸용으로 사용합니다(DEC-007 — 외부 공개 확장 시 public ID 추가로 개선).
- 비밀번호는 검증된 단방향 해시로 저장합니다.
- FastAPI 내부 API는 외부 인터넷에 직접 노출하지 않으며, 서비스 간 인증은 네트워크 격리 + `X-Internal-Token` 검증을 사용합니다(DEC-014).
- AI 호출에는 timeout, 제한된 재시도, 추적 ID를 적용합니다.
- 핵심 상태 변경은 트랜잭션으로 처리하고 중복 요청에 대한 멱등성을 설계합니다.
- 구체적인 성능 SLO, PDF 크기/페이지 제한, 보관 기간은 TBD입니다.
