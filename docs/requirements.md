## 1. 권한

| 주체 | 가능한 행동 |
| --- | --- |
| 비회원 | `LEARNER` 또는 `INSTRUCTOR` 역할을 선택한 회원가입, 로그인 |
| LEARNER | 개인 PDF 조회·업로드, 본인 세션과 퀴즈·메모리 사용, 승인된 강의실의 공개 주차·자료·공지 조회와 통합학습 |
| INSTRUCTOR | 개인 PDF 학습, 본인 강의실 개설·수정·완료 전환과 참여·주차·자료·공지 관리, 다른 강의실의 승인 멤버 참여 |
| ADMIN | 사용자와 자료 관리 기능(상세 범위 TBD) |
| Spring | 상태/데이터 저장, 권한 검증, 결정적 채점, FastAPI 호출 |
| FastAPI | 전달받은 문맥 안에서 AI 계획과 생성 수행 |

모든 리소스 접근은 역할뿐 아니라 소유권·강의실 멤버십·주차 공개 상태를 검증합니다. 공개 가입에서는 `ADMIN`을 선택할 수 없습니다(DEC-029 Accepted). 강의실 최소셋은 DEC-030에 따라 포함하고 Course·Lecture·Assignment·Notification은 제외합니다.

## 3. 공통 예외 상황

- 인증 토큰 누락/만료/위조
- 다른 사용자의 자료, 세션, 퀴즈, 메모리 접근
- 존재하지 않거나 처리 중/삭제된 PDF
- 페이지 범위 초과
- 완료된 세션에 턴 또는 페이지 이동 요청
- 지원하지 않는 이벤트/퀴즈 타입
- 이미 제출된 퀴즈 재제출
- AI 응답 시간 초과, 스키마 오류, 정책 검증 실패
- 스트리밍 중 연결 종료
- 같은 이벤트의 중복 전송
- DB 저장은 실패했지만 AI 호출은 성공한 부분 실패

오류 응답 계약은 [에러 코드](error-code.md)를 따릅니다.

## 4. 비기능 요구사항 초안

- 모든 시간은 서버 저장 시 UTC를 사용하고 API는 ISO-8601로 표현합니다.
- 외부 식별자 노출 방식(BIGINT/UUID)은 구현 전 결정합니다.
- 비밀번호는 검증된 단방향 해시로 저장합니다.
- FastAPI 내부 API는 외부 인터넷에 직접 노출하지 않으며 서비스 간 인증 방식을 확정합니다.
- AI 호출에는 timeout, 제한된 재시도, 추적 ID를 적용합니다(수치: ai-integration-contract v0.4 §4).
- 핵심 상태 변경은 트랜잭션으로 처리하고 중복 요청에 대한 멱등성을 설계합니다.
- 구체적인 성능 SLO, PDF 크기/페이지 제한, 보관 기간은 TBD입니다.
