# 강사 탈퇴와 소유 강의실 종료

이 변경은 #477의 소유 강의실 종료 단위입니다. 사용자가 확정한 정책에 따라 LOCAL 비밀번호 또는 Google 토큰 재인증에 성공한 소유자가 탈퇴하면 소유한 `ACTIVE` 강의실을 `COMPLETED`로 종료합니다. 현재 역할이 변경된 사용자도 실제 소유 관계를 기준으로 처리합니다. 소유권 이전은 수행하지 않습니다.

## 트랜잭션과 경합

`ClassroomWithdrawalHook`은 기존 `UserWithdrawalHook`에 참여하고 `MANDATORY`로 원래 사용자 탈퇴 트랜잭션을 요구합니다. DB 벌크 갱신으로 소유자와 ACTIVE 조건이 일치하는 강의실의 상태·갱신 시각만 변경합니다. 갱신 전 flush, 후 persistence context clear로 관리 엔티티의 오래된 ACTIVE 상태가 종료를 덮어쓰지 않게 합니다. 사용자 삭제가 롤백되면 강의실 종료도 롤백됩니다. 실제 외부 메일·AI·파일 삭제 호출을 이 hook에 추가하지 않습니다.

이전에 종료한 강의실과 다른 소유자의 강의실은 변경하지 않습니다. 기존 멤버·평가·자료 연결과 소유자 관계는 보존하고, 기존 완료 강의실의 조회·관리 쓰기·참여·강의실 시험 제출 제한을 그대로 적용합니다. 기존 멤버의 본인 통합학습은 기존 규칙대로 유지합니다. 탈퇴 사용자의 접근 캐시는 기존 #472 경로에서 커밋 후 무효화합니다.

새 강의실 생성은 실제 DB 사용자가 ACTIVE INSTRUCTOR인지 사용자 행을 잠가 확인한 뒤 수행합니다. 탈퇴도 같은 사용자 행 잠금을 사용하므로 생성이 먼저 잠갔으면 탈퇴가 생성 커밋을 기다려 새 강의실까지 종료합니다. 탈퇴가 먼저 커밋했으면 생성이 거부됩니다. 이 사용자 행 잠금은 #471 이메일 확정·탈퇴와 같은 기준입니다. 기존 강의실 행 수정과 탈퇴의 물리 잠금 경합도 전용 MySQL에서 검사합니다.

## 검증과 적용 경계

합성 계정·강의실로 LOCAL/Google 경로, 소유한 진행 중 강의실만 종료, 이전 종료·다른 소유자의 강의실 보존, 학생 멤버 보존, 사용자·강의실 동시 롤백, 잘못된 재인증의 무변경, 생성과 탈퇴의 양쪽 순서를 검사합니다. 실제 Google 공급자·메일·AI는 호출하지 않습니다. MySQL 검증은 `127.0.0.1:33316/classroom_withdrawal_synthetic` 전용 DB의 포트·이름을 확인한 뒤에만 실행하며, 실제 학생 데이터를 사용하지 않습니다.

추가 DB migration이나 API 요청·응답 필드는 없습니다. 이 브랜치는 #472 Google 탈퇴 브랜치를 base로 하는 draft이며 이미 승인된 #480/#481/#482 통합 배포 범위에 포함되지 않습니다. develop·DEV에 반영했다고 표시하지 않습니다.

원본 PDF·렌더·외부 AI 파일의 삭제 추적·재시도·보존기간과 백업 복원 후 삭제 재적용은 #477/#408의 미완료 범위입니다. 보존기간을 임의 설정하지 않았으며 계정·강의실 종료를 물리 파일 정리 완료로 표시하지 않습니다. 사용자가 중단한 DEV material65/session54·material68/session55 복구 작업은 제외합니다.
